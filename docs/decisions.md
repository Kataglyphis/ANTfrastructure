# Owner decisions

The owner's decisions that the docs cite, oldest first, each with its date and its reason. An
instruction elsewhere states the rule; this page keeps when it was decided and why. "not recorded"
means no page in the hub states the reason.

- A D-id names an item of one decision list, and the ids repeat across lists, so the list is given in
  brackets: the 2026-09-15 audit, the oxidation review (D1 to D17) and the comparison with
  BeschleunigerBallett's C++ setup (D1 to D12), both of 2026-11-21.
- A CON id names a `BACKLOG.md` item. Done items are in `CHANGELOG.md` and its archives.
- A decision that replaces an older one says so, and the older row stays.

To add a decision, append one row: the date, the id if there is one, the decision in one sentence
and the reason in one sentence. Then write the rule itself, without the date or id, on the page that
owns it ([writing-docs.md](writing-docs.md)).
